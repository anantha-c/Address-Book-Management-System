# Address Book Management System in C

## Overview

Address Book Management System is a command-line application developed in **C** for managing contact records. The application provides functionality to add, search, edit, delete, list, save, and load contact information.

The project focuses on data structures, file handling, dynamic memory management, and modular C programming.

## Key Features

* Add new contacts
* Search contacts
* Edit existing contacts
* Delete contacts
* Display contact list
* Save contact data
* Load previously stored data
* Input validation
* Persistent data storage

## Implementation

Contact information is maintained using C data structures and dynamic memory. The application uses file handling to store contact records so that data can be preserved between program executions.

Search and management operations are implemented to efficiently access and modify stored contact information.

The application is divided into multiple source files to separate different responsibilities and improve maintainability.

## Design

The project uses:

* Structures for contact records
* Pointers for dynamic data management
* File handling for persistent storage
* Modular source files for better organization
* Standard C libraries for application functionality

## Technologies

* C
* Data Structures
* Structures
* Pointers
* File Handling
* Dynamic Memory
* Standard C Libraries

## Objective

The project was developed to gain practical experience in building a complete command-line application using C while applying data structures, dynamic memory allocation, file operations, input validation, and modular programming.

It demonstrates how basic data management functionality can be implemented from scratch without relying on external frameworks or databases.
